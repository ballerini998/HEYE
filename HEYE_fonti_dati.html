Aprire solo i dataset scelti in Python

Dalla cartella HEYE, copia in scelti gli ID dei dataset che ti servono. Il codice legge dal catalogo locale i percorsi e apre solo quei CSV.

import pandas as pd

scelti = ["labour_market_unemployment_istat_lfs", "population_current_istat"]
catalogo = pd.read_csv("data/catalog/dataset_status_tracker.csv", index_col="dataset_id")
dati = {nome: pd.read_csv(catalogo.at[nome, "file_processed"]) for nome in scelti}

Per una nuova estrazione puoi passare direttamente il CSV scaricato a pd.read_csv(). Se vuoi usarlo anche nella dashboard, armonizza prima colonne, unità e codici con lo schema dei CSV locali, consultabile in Dati e metodi → File dati caricati. Per il PDF BesT puoi partire dal CSV già estratto.
